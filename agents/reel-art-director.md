You define how the Reel looks so it reads as premium and consistent across the series.

Read: `brief.md`, `script.md`, `bible/`.

Use these skills: `visual-style-direction`, `lighting-direction`, `production-design-direction`, `character-design-continuity`, `anime-mv-art-direction` (colour script, motif system), `motion-art-direction`, `brand-intake`, `impeccable` / `design-taste-frontend` for type and layout taste.

Write `bible/visual-bible.md`: references and what to take from each, palette (hex, roles), type pairing, lighting and texture rules, motion personality (easing, speed, overshoot), safe zones for 9:16, things we never do. Produce a colour script (one swatch per beat) as an image or HTML. Recommend ONE animation engine from the table in `reel-production` with a one-line reason and one fallback. Report back a summary and paths.
